# 音效文件目录

将音频文件放入本目录即可自动生效（无需改代码）。文件名需与下表一致：

| 文件名         | 触发时机   |
| -------------- | ---------- |
| `move.mp3`     | 左右移动   |
| `rotate.mp3`   | 旋转       |
| `drop.mp3`     | 硬降落底   |
| `lock.mp3`     | 方块锁定   |
| `clear.mp3`    | 消行       |
| `levelup.mp3`  | 升级       |
| `gameover.mp3` | 游戏结束   |

说明：

- 文件缺失时游戏静默运行，不会报错。
- 音效开关可在界面上切换，状态会保存在浏览器本地。
- 映射关系定义在 `src/composables/useAudio.js`。
