# TetrisPure

> 一款基于纯前端技术栈实现的经典俄罗斯方块游戏。

全程无后端服务依赖，所有游戏逻辑、渲染计算、数据存储均在浏览器本地完成，可作为纯静态资源直接部署上线。项目采用「逻辑层与渲染层完全解耦」的架构：核心算法独立封装为 Composable，视图层基于 Canvas 2D 逐帧渲染。

界面还原经典「Good Old Tetris」掌机外观：金黄机身、黑色边框（带方块装饰）、橄榄绿单色 LCD 屏，开机显示小恐龙待机画面。

---

## ✨ 功能特性

### 核心玩法

- **7 种标准方块**（I / O / T / S / Z / J / L），采用 **7-bag 随机算法** 保证出块均衡
- **矩阵旋转 + SRS 墙踢**：实现标准超级旋转系统（Super Rotation System）墙踢表，避免贴墙旋转卡滞
- **完整操作**：左右移动、旋转、软降（加速下落）、硬降（直接落底）、暂停 / 继续 / 复位
- **碰撞检测**：实时判定边界与堆叠碰撞，所有位移与旋转前均做合法性校验
- **标准 Tetris 计分**：单 / 双 / 三 / 四行分别 100 / 300 / 500 / 800 分，再乘以当前等级；软降每格 +1、硬降每格 +2
- **等级递进**：可选起始等级（Start Line），每消除 10 行提升一级，等级越高自动下落越快
- **状态机**：覆盖「待机 → 游戏中 → 暂停 → 游戏结束」完整流转

### 界面与展示

- 掌机外壳 + 橄榄绿单色 LCD 屏，10×20 网格
- **经典砖块样式**（外圈 + 中心点）+ LCD 未点亮像素底纹
- **消行闪烁动画**，提升视觉反馈
- 开机待机画面：小恐龙像素图 + TETRIS 字样
- 屏内信息面板：Max（历史最高分）、Score（本局得分）、Start Line（起始等级）、Level（当前等级）、Next（下一方块）、实时时钟与静音状态
- 开机待机画面的恐龙会左右来回跳动
- 可点击的实体按钮：Pause(P) / Sound(S) / Reset(R) / Rotation / Drop(SPACE) / 方向键

### 增强能力

- 🔊 **音效**：基于 howler.js，音效开关可切换并本地持久化
- 📴 **离线游玩**：基于 vite-plugin-pwa 的 Service Worker 离线缓存
- 📱 **触控支持**：屏幕实体按钮支持鼠标点击与触摸操作

### 数据持久化（localStorage）

- 历史最高分
- 音效开关偏好
- 起始等级（Start Line）偏好

## 🛠 技术栈

| 分类     | 选型                                          | 说明                              |
| -------- | --------------------------------------------- | --------------------------------- |
| 工程构建 | Vite 5.x                                      | 打包、热更新与静态资源构建        |

## 🚀 快速开始

环境要求：Node.js ≥ 18。

```bash
# 安装依赖
npm install

# 启动本地开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 预览构建产物
npm run preview
```

## 📁 目录结构

```
TetrisPure/
├─ index.html              # 入口 HTML
├─ vite.config.js          # Vite + PWA 配置
├─ tailwind.config.js      # Tailwind 配置
├─ postcss.config.js       # PostCSS 配置
├─ public/
│  └─ sounds/              # 音效文件目录（见目录内 README）
└─ src/
   ├─ main.js              # 应用入口 + PWA 注册
   ├─ style.css            # 全局样式 / Tailwind 指令
   ├─ App.vue              # UI 装配（掌机外壳）+ 键盘/按钮输入分发
   ├─ game/                # 逻辑层（无渲染依赖）
   │  ├─ constants.js      # 方块/墙踢表/计分/速度/起始等级等常量
   │  ├─ board.js          # 棋盘纯函数：碰撞、旋转、消行、7-bag
   │  └─ useTetris.js      # 核心 Composable：状态机 + 主循环 + 操作动作
   ├─ composables/
   │  └─ useAudio.js       # howler 音效管理（开关持久化）
   └─ components/          # 渲染层
      ├─ GameCanvas.vue    # 主画布（LCD 砖块风格，自带渲染循环，只读状态）
      ├─ NextPreview.vue   # 下一方块预览（LCD 风格）
      └─ BezelDecor.vue    # 黑色边框上的方块装饰
```

### 架构说明

逻辑层（`src/game/`）与渲染层（`src/components/`）完全解耦：

- **逻辑层** 以纯函数 + 响应式状态机实现，不依赖任何 DOM / Canvas；`useTetris` 通过 `requestAnimationFrame` 驱动重力、消行、计分与等级。
- **渲染层** 自带独立渲染循环，每帧**只读取**逻辑层状态进行绘制，从不反向修改逻辑，保证职责清晰、易于维护与扩展。

## 🎮 操作说明

按键与屏幕实体按钮一一对应，按钮支持鼠标点击与触摸。

| 按键 / 按钮         | 功能                              |
| ------------------- | --------------------------------- |
| `←` / `→`（Left/Right） | 游戏中左右移动；待机时调节起始等级 |
| `↑`（Rotation）     | 旋转；待机时开始游戏              |
| `↓`（Down）         | 软降；待机时开始游戏             |
| `Ctrl` + `↓`        | 硬降（快速落下）                 |
| `空格`（Drop）      | 硬降；待机时开始游戏             |
| `P` / `Esc`（Pause）| 暂停 / 继续                       |
| `S`（Sound）        | 音效开关                          |
| `R`（Reset）        | 复位（回到开机待机画面）         |

> 没有独立的「开始」按钮：在待机 / 结束画面按 Rotation / Down / Drop 即可开始；用 Left / Right 调整 **Start Line（起始等级，0~9）**。

## 🔢 计分规则

| 一次消除行数 | 基础分 | 实际得分        |
| ------------ | ------ | --------------- |
| 1 行         | 100    | 100 × 当前等级  |
| 2 行         | 300    | 300 × 当前等级  |
| 3 行         | 500    | 500 × 当前等级  |
| 4 行         | 800    | 800 × 当前等级  |

- 软降：每下落 1 格 +1 分
- 硬降：每下落 1 格 +2 分
- 每累计消除 10 行提升 1 个等级

### Start Line（起始等级）

在待机 / 结束画面用 Left / Right 调整起始等级（0~9），起始等级越高初始下落越快；游戏过程中仍按消行数自动升级。设置会本地保存。

## 🔊 音效

将音频文件放入 `public/sounds/` 即可自动生效（无需改代码），文件名需与下表一致：

| 文件名         | 触发时机 |
| -------------- | -------- |
| `move.mp3`     | 左右移动 |
| `rotate.mp3`   | 旋转     |
| `drop.mp3`     | 硬降落底 |
| `lock.mp3`     | 方块锁定 |
| `clear.mp3`    | 消行     |
| `levelup.mp3`  | 升级     |
| `gameover.mp3` | 游戏结束 |

> 文件缺失时游戏静默运行，不会报错。音效开关可在界面切换，状态保存在浏览器本地。
